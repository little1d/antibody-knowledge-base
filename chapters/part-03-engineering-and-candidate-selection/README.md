# Part 03：抗体工程与候选物选择

发现能够结合靶点的抗体只是起点。候选分子还要经历人源化、亲和力成熟、Fc 或分子形式工程，并在特异性、表达、稳定性、聚集、免疫原性和体内行为等维度之间取得平衡。
