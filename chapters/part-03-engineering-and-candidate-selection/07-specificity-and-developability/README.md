# 第 07 章：特异性、成药性与多性质权衡

## 本章解决的问题

为什么一个高亲和力抗体仍然可能无法成为药物？表达、稳定性、聚集、溶解性、特异性和免疫原性如何共同形成开发门槛？

## 学习目标

- 区分亲和力、特异性、功能和可开发性。
- 理解抗体候选需要同时满足多种物理化学和生物学约束。
- 知道某些工程改造可能改善一个指标、同时恶化另一个指标。
- 理解早期风险前置为什么比后期补救更节省项目成本。

## 核心结论

- “能够结合”与“能够成为药”之间存在表达、生产、质量、安全性和体内行为等连续门槛。
- 可开发性不是单一分数，而是一组与分子形式、浓度、制剂和工艺条件相关的属性。
- 多目标优化的重点不是找到所有指标的数学最大值，而是在项目约束下寻找可接受平衡。

## 常见误区

- 只看亲和力，不看特异性和开发属性。
- 把单一计算评分称为“可开发性”。
- 认为实验室小规模表达成功就证明工业生产可行。
