# 抗体结构

## 为什么需要理解它

抗体结构把序列、结合、效应功能和工程风险连接到一起。序列模型、结构预测、复合物建模、亲和力成熟和可开发性预测使用的“抗体”，可能是单条链、Fv、Fab、完整 IgG 或其他格式；如果不说明结构层级，输入和标签就很容易错位。

## 经典 IgG 的整体结构

经典 IgG 可以近似看成一个 Y 形分子，由两条相同重链和两条相同轻链组成。链之间通过非共价作用和二硫键维持整体结构。

Y 形的两个“手臂”主要负责抗原识别，底部“柄”主要连接下游效应和半衰期。这个图像有助于入门，但真实抗体是动态分子；铰链、糖基化和结构域之间的相对运动都会影响功能。

## 重链、轻链和结构域

每条链由多个免疫球蛋白结构域构成：

- **重链可变域（VH）**和**轻链可变域（VL）**共同形成一个抗原结合位点。
- **轻链恒定域（CL）**和重链第一恒定域（CH1）参与 Fab 的稳定结构。
- 重链后续恒定域构成 Fc 主体，并与 Fc 受体、补体和新生儿 Fc 受体等相互作用。

不同抗体类别的重链恒定区不同，因此效应功能、组织分布和聚合形式也不同。

## Fab、Fv 与 Fc

- **Fv**：由 VH 和 VL 组成，是最小的完整可变区识别单元之一。
- **Fab**：包含 VH/VL 以及 CH1/CL，保留一个抗原结合位点。
- **Fc**：由重链恒定区的一部分构成，参与受体结合、补体作用、半衰期调控和某些纯化过程。

完整 IgG 通常具有两个抗原结合位点。Fab 常用于研究单价结合，完整 IgG 的表观结合则可能受到双价性影响。

## CDR 与框架区

VH 和 VL 中各有三个互补决定区（CDR1、CDR2、CDR3），六个 CDR 共同塑造主要抗原结合表面。CDR3，特别是重链 CDR3，通常具有较高序列和构象多样性。

CDR 并不是唯一参与结合的区域。框架区负责支撑可变域折叠、重轻链界面和 CDR 构象，有时也直接接触抗原。人源化或亲和力成熟中，框架突变可能改变结合和稳定性。

## 铰链与柔性

铰链区连接 Fab 与 Fc，使两个结合臂具有一定相对运动能力。这种柔性帮助抗体适应不同空间距离的表位，但也使完整抗体的构象比单个结构域复杂。

对建模而言，准确预测单个 Fv 或 Fab 并不等于准确描述完整 IgG 在溶液、细胞表面或多价抗原环境中的构象集合。

## 二硫键与糖基化

抗体内部和链间二硫键有助于稳定结构。Fc 区通常含有保守糖基化位点，糖链组成可能影响 Fc 结构、受体结合和效应功能。

只使用氨基酸序列或无糖结构进行建模时，应明确哪些生物学效应没有被表示。

## 编号与边界

抗体序列常使用 IMGT、Kabat、Chothia 等编号或 CDR 定义。不同体系对插入位点和 CDR 边界的处理可能不同。

记录突变时至少要说明：

- 重链还是轻链；
- 使用的编号体系；
- 参考序列或起始抗体；
- 研究的是成熟序列编号还是胚系对齐位置。

缺少这些信息的突变记录很难跨数据集复用。

## 对计算任务的意义

| 任务 | 最低需要明确的结构层级 |
|---|---|
| 抗体序列表征 | 单链、配对重轻链、胚系和克隆关系 |
| 单体结构预测 | Fv、Fab 或完整抗体范围 |
| 复合物预测 | 抗体格式、抗原状态和可能表位 |
| 亲和力突变预测 | 界面、分子形式、参考序列与实验条件 |
| Fc 功能预测 | Fc 亚型、糖基化和受体背景 |

## 容易混淆的概念

- **Fv 不等于 Fab**：Fab 还包含恒定结构域。
- **Fab 结合结果不等于完整 IgG 结果**：价数、空间构型和 Fc 相关影响不同。
- **结构相似不等于功能相同**：微小界面变化、动力学和下游效应都可能改变结果。

## 关键结论

抗体是模块化但相互耦合的分子。可变区决定主要识别界面，Fc 连接半衰期和效应功能，分子形式和柔性又会改变整体行为。任何数据或模型都应明确它表示的是哪一层结构。
