# 亲和力、亲合力与特异性

## 为什么需要理解它

“结合更强”在不同论文和实验中可能指完全不同的量：平衡 KD 更低、解离更慢、细胞表面信号更强、展示富集更高，或多价分子更难从抗原脱落。如果不区分这些概念，模型就可能优化错误的目标。

## 三个核心概念

### 亲和力（affinity）

亲和力通常描述一个结合位点与一个配体位点之间的相互作用强弱。在简单的一步可逆模型中：

```text
Ab + Ag ⇌ Ab·Ag
```

结合速率常数为 `kon`，解离速率常数为 `koff`，平衡解离常数为：

```text
KD = koff / kon
```

在该模型和一致单位下，KD 越小，平衡时达到相同占有比例所需的游离配体浓度通常越低。但 KD 不是脱离实验条件的绝对属性；固定方式、构象状态、温度、缓冲体系、传质和拟合模型都可能影响结果。

### 亲合力（avidity）

亲合力描述多价相互作用共同产生的总体结合效果。完整 IgG 有两个抗原结合位点；IgM 等形式具有更高价数。当一个结合臂解离后，另一个结合臂仍可能保持连接，使分子更容易重新结合。

因此，多价体系测得的表观结合强度可能远高于单个位点亲和力。把多价 IgG 的表观 KD 与单价 Fab 的 KD 直接比较，往往会混淆分子价数和真实位点性质。

### 特异性（specificity）

特异性描述抗体区分目标与其他分子的能力。高亲和力并不保证高特异性：一个抗体可以强烈结合目标，也强烈结合相似蛋白或非目标表面。

研发中至少要考虑：

- 是否结合相关蛋白或同一家族成员；
- 是否出现非特异性、多反应性或基质相关结合；
- 是否与非靶组织发生不希望的结合；
- 不同物种间的结合是否满足药理和毒理研究需要。

## kon 与 koff 为什么要分别看

相同 KD 可以来自不同动力学组合：

- 快速结合、快速解离；
- 缓慢结合、缓慢解离。

两者在给药浓度变化、短暂接触、受体内吞或组织渗透环境中可能表现不同。项目可能更关注慢解离，也可能需要适当解离来改善组织分布或受体周转；不能只凭“越慢越好”作普遍判断。

## 从分子结合到功能

结合参数与功能之间没有固定的一一映射。功能还可能受到以下因素影响：

- 表位是否阻断关键相互作用；
- 抗体是否诱导受体聚集、内吞或构象变化；
- 细胞表面靶点密度；
- 抗体价数和几何构型；
- Fc 效应和免疫细胞环境；
- 体内暴露和组织分布。

因此，亲和力成熟通常需要同时观察功能和可开发性，而不是只追求 KD 数值。

## 常见实验量不能直接互换

| 量 | 主要反映什么 | 不能自动推出什么 |
|---|---|---|
| KD、kon、koff | 特定模型和条件下的结合动力学 | 细胞功能、体内药效 |
| 展示富集值 | 特定筛选流程中的相对保留与扩增 | 绝对 KD |
| 流式荧光强度 | 细胞/颗粒上的结合或表达相关信号 | 单位点亲和力 |
| 模型 score | 模型定义的排序或概率 | 实验亲和力、临床效力 |
| IC50/EC50 | 特定功能实验中的浓度–效应关系 | 纯粹的分子结合常数 |

## 对计算任务的意义

训练“亲和力模型”前，应先回答：

1. 标签是 KD、koff、富集值还是分类结果？
2. 抗体是 Fab、scFv、IgG 还是多价格式？
3. 抗原是可溶蛋白、固定表面还是细胞膜蛋白？
4. 数据来自同一实验体系还是多来源汇总？
5. 模型需要预测绝对值、方向还是项目内相对排序？

很多场景中，预测“哪些突变更值得测试”比跨抗原、跨体系预测绝对 KD 更现实。

## 容易混淆的概念

- **低 KD 与低 koff**：低 KD 可以由更快结合或更慢解离共同造成。
- **亲和力与效力**：效力是功能实验概念，不是结合常数的另一种写法。
- **特异性与选择性**：不同领域用法略有差异，文档中应明确比较对象和实验定义。

## 关键结论

亲和力描述单个位点层面的结合，亲合力包含多价协同，特异性描述对目标与非目标的区分。研发和建模时必须保留分子形式、实验体系和标签定义，不能把所有“结合更好”的读数压缩成同一个目标。
