# 第 02 章：抗体的结构、功能与分子形式

## 本章解决的问题

抗体的哪些部分负责识别抗原，哪些部分负责招募免疫效应？亲和力、亲合力和特异性有什么区别？不同分子形式为什么会改变实验读数和成药属性？

## 学习目标

- 识别重链、轻链、可变区、恒定区、Fab、Fc、CDR 和框架区。
- 区分 affinity、avidity 和 specificity。
- 理解 Fc 与 FcRn、FcγR 和补体系统的关系。
- 知道 IgG、IgA、IgM 以及工程化抗体形式不能用同一套直觉直接比较。

## 前置知识

[第 01 章](../01-immune-system-and-antibody-generation)。

## 核心结论

- Fab 主要决定识别对象和结合方式，Fc 主要连接半衰期、免疫效应和部分生产纯化属性。
- KD 描述特定测量条件下的平衡结合关系；多价结合产生的总体表观强度不能简单当作单个位点亲和力。
- 分子形式会改变价数、空间构型、效应功能和药代行为，因此实验结果必须连同构型一起解释。

## 与上下游的关系

本章为第 05 章实验读数、第 06 章工程改造、第 07 章可开发性和第 12 章结构/亲和力任务提供术语基础。

## 常见误区

- 把 Fab 和 Fc 简化为完全独立、互不影响的模块。
- 把"结合更强"直接理解成"药效更好"。
- 忽略单价片段、完整 IgG 和多价格式之间的测量差异。

## 抗体结构

### 为什么需要理解它

抗体结构把序列、结合、效应功能和工程风险连接到一起。序列模型、结构预测、复合物建模、亲和力成熟和可开发性预测使用的"抗体"，可能是单条链、Fv、Fab、完整 IgG 或其他格式；如果不说明结构层级，输入和标签就很容易错位。

### 经典 IgG 的整体结构

经典 IgG 可以近似看成一个 Y 形分子，由两条相同重链和两条相同轻链组成。链之间通过非共价作用和二硫键维持整体结构。

Y 形的两个"手臂"主要负责抗原识别，底部"柄"主要连接下游效应和半衰期。这个图像有助于入门，但真实抗体是动态分子；铰链、糖基化和结构域之间的相对运动都会影响功能。

### 重链、轻链和结构域

每条链由多个免疫球蛋白结构域构成：

- **重链可变域（VH）**和**轻链可变域（VL）**共同形成一个抗原结合位点。
- **轻链恒定域（CL）**和重链第一恒定域（CH1）参与 Fab 的稳定结构。
- 重链后续恒定域构成 Fc 主体，并与 Fc 受体、补体和新生儿 Fc 受体等相互作用。

不同抗体类别的重链恒定区不同，因此效应功能、组织分布和聚合形式也不同。

### Fab、Fv 与 Fc

- **Fv**：由 VH 和 VL 组成，是最小的完整可变区识别单元之一。
- **Fab**：包含 VH/VL 以及 CH1/CL，保留一个抗原结合位点。
- **Fc**：由重链恒定区的一部分构成，参与受体结合、补体作用、半衰期调控和某些纯化过程。

完整 IgG 通常具有两个抗原结合位点。Fab 常用于研究单价结合，完整 IgG 的表观结合则可能受到双价性影响。

### CDR 与框架区

VH 和 VL 中各有三个互补决定区（CDR1、CDR2、CDR3），六个 CDR 共同塑造主要抗原结合表面。CDR3，特别是重链 CDR3，通常具有较高序列和构象多样性。

CDR 并不是唯一参与结合的区域。框架区负责支撑可变域折叠、重轻链界面和 CDR 构象，有时也直接接触抗原。人源化或亲和力成熟中，框架突变可能改变结合和稳定性。

### 铰链与柔性

铰链区连接 Fab 与 Fc，使两个结合臂具有一定相对运动能力。这种柔性帮助抗体适应不同空间距离的表位，但也使完整抗体的构象比单个结构域复杂。

对建模而言，准确预测单个 Fv 或 Fab 并不等于准确描述完整 IgG 在溶液、细胞表面或多价抗原环境中的构象集合。

### 二硫键与糖基化

抗体内部和链间二硫键有助于稳定结构。Fc 区通常含有保守糖基化位点，糖链组成可能影响 Fc 结构、受体结合和效应功能。

只使用氨基酸序列或无糖结构进行建模时，应明确哪些生物学效应没有被表示。

### 编号与边界

抗体序列常使用 IMGT、Kabat、Chothia 等编号或 CDR 定义。不同体系对插入位点和 CDR 边界的处理可能不同。

记录突变时至少要说明：

- 重链还是轻链；
- 使用的编号体系；
- 参考序列或起始抗体；
- 研究的是成熟序列编号还是胚系对齐位置。

缺少这些信息的突变记录很难跨数据集复用。

### 对计算任务的意义

| 任务 | 最低需要明确的结构层级 |
|---|---|
| 抗体序列表征 | 单链、配对重轻链、胚系和克隆关系 |
| 单体结构预测 | Fv、Fab 或完整抗体范围 |
| 复合物预测 | 抗体格式、抗原状态和可能表位 |
| 亲和力突变预测 | 界面、分子形式、参考序列与实验条件 |
| Fc 功能预测 | Fc 亚型、糖基化和受体背景 |

### 容易混淆的概念

- **Fv 不等于 Fab**：Fab 还包含恒定结构域。
- **Fab 结合结果不等于完整 IgG 结果**：价数、空间构型和 Fc 相关影响不同。
- **结构相似不等于功能相同**：微小界面变化、动力学和下游效应都可能改变结果。

### 关键结论

抗体是模块化但相互耦合的分子。可变区决定主要识别界面，Fc 连接半衰期和效应功能，分子形式和柔性又会改变整体行为。任何数据或模型都应明确它表示的是哪一层结构。

## 亲和力、亲合力与特异性

### 为什么需要理解它

"结合更强"在不同论文和实验中可能指完全不同的量：平衡 KD 更低、解离更慢、细胞表面信号更强、展示富集更高，或多价分子更难从抗原脱落。如果不区分这些概念，模型就可能优化错误的目标。

### 三个核心概念

#### 亲和力（affinity）

亲和力通常描述一个结合位点与一个配体位点之间的相互作用强弱。在简单的一步可逆模型中：

```text
Ab + Ag ⇌ Ab·Ag
```

结合速率常数为 `kon`，解离速率常数为 `koff`，平衡解离常数为：

```text
KD = koff / kon
```

在该模型和一致单位下，KD 越小，平衡时达到相同占有比例所需的游离配体浓度通常越低。但 KD 不是脱离实验条件的绝对属性；固定方式、构象状态、温度、缓冲体系、传质和拟合模型都可能影响结果。

#### 亲合力（avidity）

亲合力描述多价相互作用共同产生的总体结合效果。完整 IgG 有两个抗原结合位点；IgM 等形式具有更高价数。当一个结合臂解离后，另一个结合臂仍可能保持连接，使分子更容易重新结合。

因此，多价体系测得的表观结合强度可能远高于单个位点亲和力。把多价 IgG 的表观 KD 与单价 Fab 的 KD 直接比较，往往会混淆分子价数和真实位点性质。

#### 特异性（specificity）

特异性描述抗体区分目标与其他分子的能力。高亲和力并不保证高特异性：一个抗体可以强烈结合目标，也强烈结合相似蛋白或非目标表面。

研发中至少要考虑：

- 是否结合相关蛋白或同一家族成员；
- 是否出现非特异性、多反应性或基质相关结合；
- 是否与非靶组织发生不希望的结合；
- 不同物种间的结合是否满足药理和毒理研究需要。

### kon 与 koff 为什么要分别看

相同 KD 可以来自不同动力学组合：

- 快速结合、快速解离；
- 缓慢结合、缓慢解离。

两者在给药浓度变化、短暂接触、受体内吞或组织渗透环境中可能表现不同。项目可能更关注慢解离，也可能需要适当解离来改善组织分布或受体周转；不能只凭"越慢越好"作普遍判断。

### 从分子结合到功能

结合参数与功能之间没有固定的一一映射。功能还可能受到以下因素影响：

- 表位是否阻断关键相互作用；
- 抗体是否诱导受体聚集、内吞或构象变化；
- 细胞表面靶点密度；
- 抗体价数和几何构型；
- Fc 效应和免疫细胞环境；
- 体内暴露和组织分布。

因此，亲和力成熟通常需要同时观察功能和可开发性，而不是只追求 KD 数值。

### 常见实验量不能直接互换

| 量 | 主要反映什么 | 不能自动推出什么 |
|---|---|---|
| KD、kon、koff | 特定模型和条件下的结合动力学 | 细胞功能、体内药效 |
| 展示富集值 | 特定筛选流程中的相对保留与扩增 | 绝对 KD |
| 流式荧光强度 | 细胞/颗粒上的结合或表达相关信号 | 单位点亲和力 |
| 模型 score | 模型定义的排序或概率 | 实验亲和力、临床效力 |
| IC50/EC50 | 特定功能实验中的浓度–效应关系 | 纯粹的分子结合常数 |

### 对计算任务的意义

训练"亲和力模型"前，应先回答：

1. 标签是 KD、koff、富集值还是分类结果？
2. 抗体是 Fab、scFv、IgG 还是多价格式？
3. 抗原是可溶蛋白、固定表面还是细胞膜蛋白？
4. 数据来自同一实验体系还是多来源汇总？
5. 模型需要预测绝对值、方向还是项目内相对排序？

很多场景中，预测"哪些突变更值得测试"比跨抗原、跨体系预测绝对 KD 更现实。

### 容易混淆的概念

- **低 KD 与低 koff**：低 KD 可以由更快结合或更慢解离共同造成。
- **亲和力与效力**：效力是功能实验概念，不是结合常数的另一种写法。
- **特异性与选择性**：不同领域用法略有差异，文档中应明确比较对象和实验定义。

### 关键结论

亲和力描述单个位点层面的结合，亲合力包含多价协同，特异性描述对目标与非目标的区分。研发和建模时必须保留分子形式、实验体系和标签定义，不能把所有"结合更好"的读数压缩成同一个目标。

## Fc 与效应功能

### 为什么需要理解它

Fab 决定抗体主要识别谁，Fc 决定抗体如何连接机体中的回收、免疫细胞和补体系统。相同的抗原识别区域接到不同 Fc 上，可能具有不同半衰期、细胞杀伤能力和安全性。

### Fc 的主要作用

Fc 是抗体重链恒定区形成的功能模块。它可以参与：

- 与新生儿 Fc 受体（neonatal Fc receptor, FcRn）结合，影响抗体回收和体内半衰期；
- 与 Fcγ 受体（Fcγ receptor, FcγR）结合，招募不同免疫细胞；
- 与补体成分相互作用，启动补体相关效应；
- 与 Protein A/G 等配基结合，影响常用纯化策略；
- 通过亚型、糖基化和工程突变改变效应强度。

### FcRn 与半衰期

FcRn 参与 IgG 的细胞内回收。IgG 被细胞摄取后，在酸性内体环境中与 FcRn 结合，可以减少进入溶酶体降解的比例，并在细胞表面释放回循环。

这套机制是 IgG 具有较长体内半衰期的重要原因之一。Fc 工程可以调节这一过程，但"更强结合"并不在所有 pH 和条件下都等于更长半衰期；结合与释放的条件依赖性很重要。

### ADCC、ADCP 与 CDC

#### ADCC

抗体依赖的细胞介导的细胞毒作用（antibody-dependent cellular cytotoxicity, ADCC）通常指抗体包被靶细胞后，通过 FcγR 招募自然杀伤细胞等效应细胞，促使靶细胞被杀伤。

#### ADCP

抗体依赖的细胞吞噬作用（antibody-dependent cellular phagocytosis, ADCP）指抗体标记目标后，促进巨噬细胞等吞噬细胞摄取目标。

#### CDC

补体依赖的细胞毒作用（complement-dependent cytotoxicity, CDC）涉及抗体结合靶表面后促进补体级联反应，最终可能造成靶细胞损伤或清除。

这些效应是否发生，取决于 Fc 亚型、糖基化、抗原密度、表位位置、抗体空间排列、受体表达和实验体系等多种因素。

### Fc 并非总要"更强"

某些治疗策略需要增强效应细胞杀伤；另一些策略只希望阻断配体或受体，可能需要降低不希望的 Fc 效应。对同一靶点，不同适应症、组织和安全性风险也可能要求不同 Fc 设计。

因此，Fc 工程不是单方向最大化问题，而是作用机制约束下的设计问题。

### 糖基化的影响

Fc 糖基化会影响结构和受体相互作用。细胞株、培养条件和生产工艺可能改变糖型分布，因此 Fc 功能不仅由氨基酸序列决定，也与生产过程和产品质量控制相关。

这也是抗体序列模型难以独立覆盖全部 Fc 功能的原因之一。

### 对实验与建模的意义

解释 Fc 数据时至少要记录：

- 抗体亚型和 Fc 突变；
- 糖基化或生产背景；
- 受体类型和物种；
- 靶细胞、效应细胞及其比例；
- 抗原密度和实验终点。

跨实验室合并 ADCC 或 Fc 受体数据时，这些差异会形成明显的标签异质性。

### 容易混淆的概念

- **FcRn 与 FcγR**：前者主要与回收和半衰期相关；后者包括多种激活性或抑制性受体，参与免疫效应。
- **结合 Fc 受体与产生细胞功能**：受体结合是机制的一部分，不自动等于最终杀伤或吞噬结果。
- **Fc 静默与完全无功能**：降低特定受体或补体作用不代表分子在所有上下文中完全没有 Fc 相关影响。

### 关键结论

Fc 把抗体识别事件连接到半衰期、免疫细胞和补体系统。它的功能由序列、亚型、糖基化、分子排列和实验环境共同决定。Fc 设计必须从目标作用机制和安全性出发，而不是简单追求更强效应。

## 常见抗体分子形式

### 为什么需要理解它

"抗体"不是单一分子格式。天然免疫球蛋白有不同类别，药物研发又使用 Fab、scFv、完整 IgG、双特异性抗体、单域抗体和抗体偶联药物等形式。格式会改变价数、几何结构、效应功能、半衰期、组织分布、生产和实验读数。

### 天然免疫球蛋白类别

#### IgG

IgG 是许多治疗性抗体采用的经典框架，通常为单体 Y 形结构，具有两个抗原结合位点和一个 Fc 区。不同 IgG 亚型的 Fc 受体与补体作用有所差异。

#### IgM

分泌型 IgM 常形成多聚结构，具有较高价数，常见于早期免疫应答。高价数可以带来显著亲合力效应，因此不能把 IgM 的总体结合直接解释为单个位点亲和力。

#### IgA

IgA 与黏膜免疫密切相关，可有单体和二聚体等形式。其组织环境和受体系统与典型血清 IgG 不同。

其他类别也具有独特生物学功能，本版先建立与药物研发最常见概念相关的入口。

### 常见研究与工程格式

#### Fab

Fab 保留一个抗原结合位点，不包含完整 Fc。它适合研究单价结合，也可以作为药物形式，但通常具有与完整 IgG 不同的半衰期和效应功能。

#### scFv

单链可变片段（single-chain variable fragment, scFv）使用连接肽将 VH 与 VL 串联。它便于某些展示和工程系统，但连接方式、取向和稳定性会影响表现。

#### 单域抗体与纳米抗体

单域抗体只使用一个可变域完成识别，分子更小，能够进入某些传统抗体难以到达的空间。较小尺寸也会改变半衰期、价数和生产策略。

#### 双特异性和多特异性抗体

这类分子可以同时识别两个或多个靶点或表位。它们能够实现细胞桥接、双通路阻断或新的几何机制，但也带来链配对、稳定性、聚集和生产复杂度。

#### 抗体偶联药物

抗体偶联药物（antibody-drug conjugate, ADC）把抗体的靶向能力与连接子和有效载荷结合。其性能不只由抗体决定，还取决于偶联位点、药物抗体比、连接子稳定性、内吞和载荷机制。

### 格式如何改变实验解释

| 变化 | 可能带来的影响 |
|---|---|
| 从 Fab 到 IgG | 从单价到双价，增加 Fc、改变半衰期和表观结合 |
| 从 IgG 到多价格式 | 增强亲合力，也可能改变聚集和组织分布 |
| 加入第二特异性 | 引入新的几何约束、链配对和功能组合 |
| 去除或修改 Fc | 改变效应功能、回收、纯化和体内行为 |
| 加入载荷 | 引入偶联异质性、内吞和释放机制 |

因此，模型或实验不能只记录"序列"和"活性"，还应记录分子格式及构建细节。

### 格式选择是一种机制设计

选择格式不是把同一识别序列装进不同外壳。格式会改变：

- 抗原结合价数和空间距离；
- 是否需要 Fc 效应；
- 目标组织和暴露方式；
- 生产、纯化和质量控制难度；
- 安全性和免疫原性风险；
- 最适合的实验验证体系。

因此，格式选择应从目标产品画像和作用机制出发。

### 容易混淆的概念

- **分子更小不等于一定更好**：可能改善组织进入，也可能加快清除。
- **双特异性不等于两个单抗简单相加**：几何结构和同时结合条件可能产生新行为。
- **相同可变区不等于相同药效**：Fc、价数、连接方式和暴露都可能改变结果。

### 关键结论

抗体格式是研发设计变量，而不是结果展示方式。任何结合、功能或 AI 数据都应记录使用的分子形式；跨格式比较必须明确价数、Fc、几何结构和实验条件的变化。
