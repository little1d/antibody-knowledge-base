# 第 04 章：抗体文库、展示与筛选

## 本章解决的问题

怎样把巨大的抗体序列空间变成实验可探索的文库？噬菌体、酵母或细胞展示如何把序列与表型联系起来？为什么百万级甚至更大的文库仍然可能错过最佳候选？

## 学习目标

- 理解文库规模、多样性、有效成员和实际覆盖范围的区别。
- 理解展示、选择、扩增和逐轮加压的基本循环。
- 知道富集信号为何不能自动等同于 KD 或功能。
- 理解文库设计和实验偏倚如何塑造最终数据集。

## 核心结论

- 名义文库规模不等于正确表达、折叠并保留功能的有效文库规模。
- 筛选结果反映抗原形式、展示体系、洗涤条件、生长偏倚和检测方法的共同作用。
- 展示筛选适合缩小候选集合，最终结论仍需要回到目标抗体格式进行表达、纯化和完整验证。

## 常见误区

- 把更大的文库等同于更好的候选。
- 把 enrichment 直接当成亲和力标签。
- 忽略展示格式和完整 IgG 之间的构象与价数差异。
