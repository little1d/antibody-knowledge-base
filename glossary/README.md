# 抗体药物研发术语速查

正文中首次出现的术语在此处提供一句话释义。当正文因篇幅限制无法展开某个术语时，读者可在此快速查阅。

## A-D

| 术语 | 一句话解释 |
|---|---|
| ADCC | 抗体依赖的细胞介导的细胞毒作用，由抗体 Fc 招募效应细胞参与靶细胞杀伤 |
| ADCP | 抗体依赖的细胞吞噬作用，促进巨噬细胞等吞噬抗体标记的目标 |
| ADA | 抗药抗体，机体针对治疗产品产生的抗体，可能影响暴露、疗效或安全性 |
| ADC | 抗体偶联药物，由抗体、连接子和有效载荷共同组成 |
| ADME | 吸收、分布、代谢和排泄；用于抗体时不能原样套用典型小分子框架 |
| AbTAC | 抗体基 PROTAC，使用双特异性抗体格式招募膜结合 E3 连接酶诱导目标蛋白降解 |
| affinity | 亲和力，通常描述单个结合位点之间的相互作用 |
| AIDD | AI 辅助药物发现，把模型、数据和实验用于候选发现与研发决策 |
| avidity | 亲合力，多价相互作用共同产生的总体结合效果 |
| BCR | B 细胞受体，位于 B 细胞表面的免疫球蛋白受体复合物 |
| BLA | 生物制品许可申请，美国生物制品上市许可常用申请类型 |
| BLI | 生物层干涉，用光学干涉信号实时观察结合与解离 |
| CDR | 互补决定区，抗体可变区中主要塑造抗原结合表面的高变区域 |
| CDC | 补体依赖的细胞毒作用，由抗体促进补体级联并参与靶目标清除 |
| CMC | 化学、生产和质量控制，把研究分子转化为可重复生产的受控产品 |
| CQA | 关键质量属性，需要控制在适当范围以保证产品质量、安全性和效力的属性 |

## E-M

| 术语 | 一句话解释 |
|---|---|
| EC50 | 在特定实验中产生一半最大效应所需的浓度，不等于 KD |
| Fab | 抗原结合片段，包含一个抗原结合位点但不含完整 Fc |
| FACS | 荧光激活细胞分选，可按展示量、抗原结合等信号分选细胞 |
| Fc | 抗体恒定区形成的效应模块，连接 Fc 受体、补体和半衰期调控 |
| FcRn | 新生儿 Fc 受体，参与 IgG 的细胞内回收和半衰期调控 |
| FTO | 实施自由，评估研发、生产或商业化是否可能落入他人专利权利范围 |
| Fv | 由 VH 与 VL 组成的可变区识别单元 |
| GLP | 良好实验室规范，强调正式非临床研究的数据质量、完整性和可追溯性 |
| IgG | 最常见的治疗性抗体框架之一，通常为带两个结合臂和 Fc 的单体 |
| IgM | 初始抗体类别，五聚体结构，补体激活能力强 |
| IgD | 主要表达于初始 B 细胞表面的抗体类别，与 IgM 共同作为 BCR |
| IgA | 黏膜免疫主力抗体，二聚体形式分泌 |
| IgE | 参与抗寄生虫和过敏反应的抗体类别，结合肥大细胞 |
| IND | 新药临床试验申请，用于请求开展人体临床研究 |
| IND-enabling | 为支持 IND 而开展的一组药理、毒理、质量和相关正式研究 |
| KD | 平衡解离常数；在简单模型中 `KD = koff / kon` |
| koff | 解离速率常数，描述复合物解离速度 |
| kon | 关联速率常数，描述抗体与抗原形成复合物的速度 |
| MAA | 上市许可申请，欧洲药品上市许可常用申请类型 |

## N-Z

| 术语 | 一句话解释 |
|---|---|
| NGS | 高通量测序，可用于观察文库序列在筛选轮次或分区中的丰度变化 |
| NOAEL | 给定毒理研究中未观察到处理相关不良反应的最高测试剂量 |
| PCC | 临床前候选物，经内部正式确定进入系统临床前开发的分子 |
| PD | 药效动力学，研究暴露或浓度与生物效应的关系 |
| PK | 药代动力学，描述药物浓度随时间的体内变化 |
| PLM | 蛋白语言模型，从大规模蛋白序列学习氨基酸上下文和统计规律 |
| PROTAC | 蛋白降解靶向嵌合体，利用小分子将目标蛋白招募至 E3 连接酶使其泛素化降解 |
| rNPV | 风险调整净现值，把未来现金流、开发成本、时间和阶段成功概率结合起来的估值方法 |
| scFv | 单链可变片段，用连接肽把 VH 与 VL 串联 |
| SPR | 表面等离子共振，通过表面光学响应实时观察结合和解离 |
| specificity | 特异性，抗体区分目标与非目标的能力 |
| TPP | 目标产品画像，描述未来产品希望达到的适应症、疗效、安全、给药和差异化属性 |
| TPD | 靶向蛋白降解，利用细胞自身的蛋白降解机器选择性清除目标蛋白 |
| Tfh | 滤泡辅助 T 细胞，在生发中心为 B 细胞提供 CD40L 和细胞因子帮助 |
| V(D)J | 抗体可变区基因片段重排机制，是抗体多样性的主要来源之一 |
| VH/VL | 抗体重链/轻链可变域，共同形成主要抗原结合界面 |
