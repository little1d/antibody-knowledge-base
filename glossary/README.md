# 抗体药物研发术语速查

本页用于快速定位术语，不代替正文中的机制解释。定义均为本知识库语境下的入门版本；具体实验条件、适用范围和常见误区请进入链接页面阅读。

## 使用方式

- 按英文缩写查找中文含义。
- 点击正文链接理解适用条件、实验读数和常见误区。
- 同一个缩写在不同语境有多种含义时，以正文上下文为准。
